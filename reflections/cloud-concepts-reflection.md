# Cloud Concepts Reflection

Cloud computing has become a part of my daily life because many of the applications I use rely on cloud services. Three cloud services I regularly use are Google Drive, Facebook Messenger, and Canva.

Google Drive is an example of Software as a Service (SaaS) because it allows users to store, access, and share files through a web browser or mobile application without installing or managing the underlying infrastructure. It uses a Public Cloud deployment model since it is available to anyone with a Google account over the internet.

Facebook Messenger is also classified as SaaS because it provides messaging, voice calls, and video calls as a complete application that users can access without maintaining servers or software. It is deployed through the Public Cloud because Meta provides the service to millions of users worldwide through shared cloud infrastructure.

Canva is another SaaS application because it offers online graphic design tools that users can access through a browser without installing professional design software. Like the others, it uses the Public Cloud deployment model since it is available to the general public through the internet.

Version control is essential when working with cloud infrastructure because cloud resources and configurations change frequently. Without version control, it is difficult to track who made changes, identify mistakes, or restore previous versions when problems occur. Git helps record every modification, making development more organized and reliable.

GitHub enhances collaboration by providing a central repository where team members can work together efficiently. Features such as branches, pull requests, code reviews, and commit history allow developers to propose changes, review each other's work, and merge updates safely. GitHub also maintains a complete history of every change, making it easier to identify errors, recover previous versions, and ensure that cloud projects remain stable, organized, and easier to maintain.
