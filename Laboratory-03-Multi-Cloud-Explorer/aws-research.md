AWS Research

Brief Overview

Amazon Web Services (AWS) is a public cloud computing platform that provides a wide range of services for computing, storage, databases, networking, security, analytics, and application development. AWS allows organizations to use cloud resources without having to maintain all of the physical infrastructure themselves.

Global Infrastructure

AWS organizes its global infrastructure into geographic Regions and Availability Zones. A Region is a separate geographic area, while Availability Zones are isolated locations within a Region. AWS states that each Region has at least three Availability Zones, which helps organizations design applications with greater availability and fault tolerance. (AWS Documentation)

Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services and resources. Through the console, users can create and manage services such as EC2 instances, S3 storage, VPC networks, and IAM users and permissions.

Four Core Services

1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual computing capacity in the AWS cloud. It can be used to host websites, applications, development environments, and other workloads.

2. Amazon S3

Amazon Simple Storage Service (S3) provides object storage for storing files and data. It can be used for backups, application data, media files, archives, and other objects.

3. Amazon VPC

Amazon Virtual Private Cloud (VPC) provides networking capabilities for AWS resources. It allows organizations to create virtual networks, subnets, routing configurations, and network security controls.

4. AWS IAM

AWS Identity and Access Management (IAM) helps control access to AWS resources. It allows administrators to manage users, groups, roles, and permissions.

Three Advantages

1. Wide range of services – AWS provides many services covering computing, storage, networking, databases, security, analytics, and application development.
2. Scalability – AWS resources can be increased or decreased according to workload requirements.
3. Global infrastructure – AWS provides infrastructure across many geographic Regions and Availability Zones, allowing organizations to deploy applications closer to their users and design for higher availability. (AWS Documentation)

Typical Enterprise Use Cases

AWS can be used by enterprises for:

* Web and application hosting
* Data storage and backup
* Database hosting
* E-commerce applications
* Disaster recovery
* Application development and testing
* Data analytics
* Artificial intelligence and machine learning
* Enterprise cloud migration
